# ГЕРОЙ 360° AI — исправленная полная версия

Рабочий учебный прототип для 6 класса: 11 анонимных учеников, защищённый кабинет учителя `laila.teacher`, общая база Cloudflare D1, шесть шагов литературного анализа, сохранение первоначального и исправленного ответа, проверка по пяти критериям, карта затруднений и необязательные AI-подсказки.

## Что исправлено

- Библиотечные семена сверены с официальными EPUB издательства «Атамұра» (2018, части 1 и 2).
- `«Конь с розовой гривой»` и другие неподтверждённые позиции удалены.
- Астафьев не включён в рабочую библиотеку по требованию заказчика. Для прозрачности `«Белогрудка»`, которая действительно есть в учебнике, отмечена в `data/excluded.json` и `docs/VERIFIED_WORKS.md`.
- Названия, авторы, части, уроки, страницы и доступные данные о персонажах согласованы в `data/works.json` и `worker/schema.sql`.
- AI получает только выбранное произведение, разрешённый учителем фрагмент и ответ ученика. Он не должен придумывать цитаты и не пишет готовую работу.
- Учительский пароль отсутствует в репозитории: Worker проверяет PBKDF2-хеш из Cloudflare secrets.
- Ученические коды также не хранятся открыто; D1 содержит только SHA-256-хеш с секретным pepper.

## Структура

- `index.html`, `styles.css`, `js/` — статический сайт для GitHub Pages.
- Кабинеты разделены на настоящие страницы: пять ученических, шесть учительских и отдельный `analysis.html` для маршрута литературного анализа.
- `data/works.json` — проверенная рабочая библиотека без Астафьева.
- `docs/VERIFIED_WORKS.md` — полный проверенный список, включая честную пометку об исключении.
- `docs/CONTENTS.md` — точная транскрипция контент-планов обеих частей: все уроки, понятия и страницы.
- `docs/PAGES.md` — карта 13 отдельных HTML-страниц и их назначение.
- `worker/src/index.js` — API Cloudflare Worker.
- `worker/schema.sql` — таблицы D1, 11 ученических записей У01–У11 и семена библиотеки.
- `scripts/hash-password.html` — локальный генератор соли и PBKDF2-хеша для пароля учителя.

## Честный статус

Код проверяется локальными статическими и интеграционными тестами, но он не становится опубликованным сервисом автоматически. Для реального входа нужно создать свой Cloudflare Worker, D1 и secrets. GitHub Pages без Worker показывает интерфейс, но намеренно не предлагает небезопасный «демо-вход».

Полные тексты учебника в архив не включены. Учитель добавляет только тот фрагмент, который имеет право использовать на уроке.

## Быстрый запуск интерфейса локально

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Пока Worker не настроен, защищённый вход будет заблокирован — это ожидаемо.
