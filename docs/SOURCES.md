# Проверенные источники

Проверка выполнена 29 октября 2026 года по двум официальным EPUB-файлам издательства «Атамұра».

- У. А. Жанпейс, А. Т. Есетова, Н. А. Озекбаева, А. А. Ерболатова.
- «Русский язык и литература». Учебник для 6 класса общеобразовательной школы с нерусским языком обучения.

- Часть 1: 192 страницы, ISBN 978-601-331-139-5.
- Часть 2: 208 страниц, ISBN 978-601-331-141-8.

## Метод проверки

1. Из карточек издательства скачаны официальные EPUB обеих частей.
2. Сверены титульные и выходные страницы, авторы, год, ISBN и объём.
3. Список произведений перенесён из контент-планов на страницах 4–5 обеих частей.
4. Для каждого элемента проверена стартовая страница урока в самом учебнике.
5. В библиотеку не переносились полные тексты или цитаты. Учитель добавляет законно доступный фрагмент самостоятельно.

`«Конь с розовой гривой»` в контент-планах этого издания отсутствует. В части 1 действительно есть другое произведение В. П. Астафьева — `«Белогрудка»` (урок 18, стр. 82). Оно отмечено в `data/excluded.json` и не включено в рабочую библиотеку, потому что заказчик прямо потребовал убрать Астафьева.
