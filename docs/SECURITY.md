# Модель безопасности

- Учитель: фиксированный логин `laila.teacher`, пароль проверяется по PBKDF2-SHA-256 (210 000 итераций), соль и хеш — Cloudflare secrets.
- Ученики: отдельные случайные коды; в D1 сохраняется только SHA-256 от `pepper:code`.
- Сессии: HMAC-SHA-256, срок 8 часов. Смена кода увеличивает `auth_version` и закрывает старые ученические сессии.
- API: роль проверяется сервером на каждом защищённом маршруте; интерфейс не считается границей доступа.
- CORS: разрешён только origin, заданный в `ALLOWED_ORIGINS`.
- Ограничение входа: неудачные попытки учитываются в D1 по IP в 15-минутном окне.
- Ввод: размеры тела и текстовых полей ограничены; SQL выполняется только через параметры D1.
- AI: получает минимальный контекст, не получает полный учебник, ФИО и учительские secrets.

Ограничения: базовая D1-защита от перебора подходит для маленького школьного прототипа, но не заменяет корпоративный WAF, журнал аудита, резервное копирование и официальную политику хранения данных.
